TEMU COUPON BLOG STARTER

Files included:
- index.html: homepage
- styles.css: responsive design
- articles/: four country guide pages
- robots.txt and sitemap.xml: basic crawling files

HOW TO USE:
1. Download and unzip this package.
2. Open your GitHub repository for temu-coupon-blog.
3. Upload/replace index.html, styles.css, robots.txt, sitemap.xml, and the articles folder.
4. Commit changes to the main branch.
5. Wait for Cloudflare to finish deployment, then open your workers.dev URL.

IMPORTANT:
- This starter is a static website. It does not include an admin panel or database yet.
- Before adding an admin panel, set up secure authentication and persistent storage (for example, Cloudflare D1 plus a protected Worker/API).
- Check every coupon and offer through official Temu terms. No discount is guaranteed by this template.
- Update the sitemap if you change your website domain.
